# 术语 Glossary (plain words)

| 中文 | English | 大白话 |
|---|---|---|
| 结节 | nodule | 肺里一小团圆形或类圆形的影子，直径不超过 3 厘米。大多数是良性的，是否要紧由医生结合大小、变化和个人情况判断。 |
| 肿块 | mass | 比结节大（超过 3 厘米）的影子。 |
| 磨玻璃影 | ground-glass opacity, GGO | 像毛玻璃一样的淡淡一片，里面的血管还看得见。密度约 -750 到 -300 HU。 |
| 实性 | solid | 比较致密，把血管遮住了。密度大约高于 -300 HU。 |
| 部分实性 | part-solid | 一部分磨玻璃、一部分实性。 |
| 钙化 | calcification | 变白变硬的小点，常见于旧的、稳定的病变。 |
| 胸膜下 | subpleural | 紧贴胸壁内侧。这个位置的小结节容易看漏。 |
| 叶 / 段 | lobe / segment | 右肺分上、中、下三叶，左肺分上、下两叶；每叶再分段。 |
| 磨玻璃结节 | ground-glass nodule | 呈磨玻璃样的结节。 |
| 纵隔 | mediastinum | 两肺之间的区域，有心脏、大血管、气管、食管、淋巴结。 |
| 肺门 | hilum | 气管分支和大血管进出肺的地方。 |
| 淋巴结肿大 | lymphadenopathy | 淋巴结变大，可由炎症或其他原因引起。 |
| 胸腔积液 | pleural effusion | 胸膜之间有液体。 |
| 肺气肿 | emphysema | 肺泡变大、破坏，CT 上是更黑的区域。 |
| 窗位 / 窗宽 | window level / width | 把一段密度范围拉伸成黑白图像。肺窗看肺，纵隔窗看软组织，骨窗看骨头。 |
| HU | Hounsfield unit | CT 的密度单位。空气约 -1000，水 0，骨头几百以上，肺约 -850。 |
| 层厚 / 层间距 | slice thickness / spacing | 每张断层的厚度 / 相邻两层中心的距离。越薄越能看清小东西。 |
| 轴位 / 冠状位 / 矢状位 | axial / coronal / sagittal | 从上往下看的横断面 / 从前往后的断面 / 从侧面的断面。 |
| 增强 | contrast-enhanced | 注射了造影剂，血管和血供丰富的组织更亮。 |
| 随访 | follow-up | 隔一段时间复查，看变化。 |

## 看片先验 Priors

- 肺在 CT 上约 -850 HU，肺窗里是黑的；血管和软组织较亮。
- 肺结节关注的大小约 3 到 30 毫米；小于 3 毫米很难与血管断面区分。
- 血管会在相邻层面间横向移动并与别的血管汇合；结节在几层内出现、变大、再消失。
- 贴胸膜、贴血管的结节最容易漏。
- 右肺中叶位置偏低、偏前，靠近心脏；下叶在后下方。
- 图像左侧是患者的右侧，上方是身体前方。
